3. PROJECT OVERVIEW
--------------------------------------------------------------------------------
CineSeat is an end-to-end commercial cinema booking simulation featuring 56 films,
three Delhi NCR multiplexes (Citylight, Aurora, Horizon), deterministic show schedules,
interactive 40-seat cinema hall grids (Classic, Premium, Recliner), adjacent recliner
recommendations, atomic multi-ticket checkout, promo discounts, digital admission
receipts, and automated waiting list queue reallocations upon order cancellations.

4. DATA STRUCTURES & ALGORITHMIC COMPLEXITY
--------------------------------------------------------------------------------
1. 2D Seat Matrix (Rows A-H, Cols 1-5)  : O(1) seat booking / access
2. Sliding Window Spatial Recommendation: O(R * C) optimal adjacent recliner search
3. Prefix Tree (MovieTrie)              : O(L) sub-millisecond title autocomplete
4. Binary Search Tree (MovieBST)        : O(log N + K) rating & price range queries
5. FIFO Doubly-Linked-List Queue        : O(1) waitlist allocation for sold-out shows
6. Priority Queue (Min-Heap)            : O(log N) VIP / priority member queue
7. LIFO Stack (BookingHistoryStack)     : O(1) cancellation audit log & rollback
8. Weighted Graph & Dijkstra's Algorithm: O((V + E) log V) shortest path across NCR
9. Merge Sort & Quick Sort              : O(N log N) catalogue sorting (Rating/Price)
10. Custom Chained Hash Table           : O(1) average digital ticket verification
